# Generated audiobook files

This folder is a publishing destination, not a claim that audio has already been generated.

Render with `python tools/render_audio.py --chapter 01 --format mp3` after installing Piper and FFmpeg. The file `01-the-long-table.mp3` will then be picked up automatically by the website. Repeat for other chapters or use `--all`.

Review the license of the voice model and listen to the generated audio before public release. WAV previews are ignored by Git; MP3 files may be committed when ready.
